changes. The original is read-only. The target is useful workflow coverage with
native Rust design, responsive UX and good photographic results. Python's
algorithms, numerical quirks and appearance are not compatibility requirements.
Reference fixtures are regression evidence, not a requirement to retain inferior
behavior. Remaining workflow gaps and validation limits stay explicit below.
